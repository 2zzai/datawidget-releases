# 데이터 위젯 — 배포 파일 (릴리스 전용)

이 저장소는 **데이터 위젯 앱의 APK 배포용** 공개 저장소입니다. 소스 코드는 별개인
private 리포(2zzai/datawidget)에 있습니다.

| 파일 | 설명 |
|---|---|
| `latest.json` | 최신 버전 정보 (앱이 이 파일을 읽어 업데이트를 판단) |
| `app/datawidget-v2.apk` | v2 APK (고정 서명 키로 서명됨) |

앱의 **설정 → 기타 → 업데이트 확인** 이 `latest.json` 을 조회하고,
새 버전이 있으면 APK 를 내려받아 설치 화면을 엽니다.
